# Study Buddy Application

## Project Overview
The **Study Buddy** application is designed to help students form study groups, create events, RSVP to events, and communicate with other students or groups. The app provides an intuitive interface to manage schedules, coordinate with peers, and streamline collaborative learning.

## Project Structure
The project is split into **frontend** and **backend** components:

### Frontend
- Built using **Gradle**.
- Provides the user interface and interacts with backend APIs.
- Handles group/event creation, RSVP functionality, and messaging features.

### Backend
- Built using **SpringBoot** with **Java**.
- Uses **MySQL** as the database.
- Handles RESTful API requests, data management, and business logic.

## Features
- **Group Management**: Create and join study groups.
- **Event Management**: Schedule events and RSVP.
- **Messaging**: Communicate with group members or individual students.
- **Persistent Data**: Store user, group, and event data in MySQL.
